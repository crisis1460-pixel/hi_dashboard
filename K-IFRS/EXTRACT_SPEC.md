# K-IFRS 기준서 추출 규격 (EXTRACT_SPEC)

목표: pdftotext로 변환된 K-IFRS 기준서 텍스트(`K-IFRS/txt/<번호>.txt`)를 정독하여,
"기준서 콜센터" 분석 엔진이 쓸 **구조화 JSON**을 `K-IFRS/parts/<번호>.json`에 생성한다.
**최대 망라(maximum coverage)** 모드 — 원칙·요구사항을 담은 주요 문단을 빠짐없이 추출한다.

## 입력 텍스트 특징(주의)
- pdftotext 출력이라 **목차/표/머리말 영역은 문단 순서가 뒤섞여** 있을 수 있다 → 본문(본문 시작 이후)을 기준으로 추출.
- **건너뛸 보일러플레이트**: 저작권/COPYRIGHT(영문), 표지, 목차, 페이지번호(`-12-`),
  결론도출근거(BC1~), 적용사례·실무적용지침(IE1~), 소수의견, 제·개정 의결 연혁 등.
  → 단, 부록 A "용어의 정의"는 **반드시 활용**(용어 사전·키워드 원천).
- 본문 문단은 보통 숫자(1, 2, 3 … 또는 9, 22, 26 …)로 시작하며 굵은 문단이 핵심 원칙이다(굵기 정보는 소실되니 내용으로 판단).

## 출력 스키마 — `parts/<번호>.json` (UTF-8, JSON 한 개 객체)
```json
{
  "no": "1116",
  "type": "standard | interpretation | framework",
  "name": "리스",
  "engRef": "IFRS 16",            // 알 수 있으면. 모르면 ""
  "purpose": "기준서 목적 1~2문장 요약",
  "scope": "적용범위 요약(무엇에 적용/제외)",
  "paragraphs": [
    {
      "no": "9",                  // 문단번호(원문 그대로). 범위면 "22~26", 부록이면 "A" 등
      "topic": "리스의 식별",       // 그 문단의 주제(짧은 제목)
      "summary": "한국어 1~2문장 핵심 요약(평이하게)",
      "excerpt": "원문에서 핵심 1~3문장 그대로 발췌(과도하게 길지 않게, 최대 ~400자)",
      "keywords": [ {"t":"리스","w":3}, {"t":"사용통제권","w":3}, {"t":"식별되는자산","w":2} ],
      "checklist": ["실무 점검 항목(있으면)", "..."],
      "journal": "분개 예시(해당 시, 없으면 \"\")"
    }
  ],
  "terms": [
    { "std":"리스부채", "aliases":["리스채무","미지급리스료"] }
  ]
}
```

## 추출 규칙
1. **paragraphs**: 인식·측정·표시·공시·정의·적용범위·분류 등 **요구사항/원칙을 담은 주요 문단을 최대한 모두** 담는다. 단순 예시·반복 설명은 묶거나 생략 가능. 큰 기준서는 30~80개까지 나올 수 있음(정상).
2. **keywords**: 각 문단의 회계 핵심어 2~5개. 가중치 `w` = 3(그 문단의 대표어) / 2(중요) / 1(보조). 일반 업무어는 제외.
3. **checklist**: 그 문단을 실무 적용할 때 점검할 질문/조건. 해당 없으면 빈 배열 `[]`.
4. **journal**: 전형적 분개가 있으면 `"(차) ××× / (대) ×××"` 형식. 없으면 `""`.
5. **terms**: 부록 A(용어의 정의) + 본문 핵심 용어를 표준용어로 삼고, 실무에서 쓰는 **비표준 동의어**를 aliases에 넣는다(예: 유형자산 ← 고정자산·비품·기계장치). 동의어를 모르면 빈 배열.
6. 모든 텍스트는 **한국어**. JSON 외 다른 출력 금지(파일로 저장).
7. 확신 없는 수치·조문번호는 지어내지 말 것. 원문에 있는 번호만 사용.

## 처리 절차
1. 배정받은 `txt/<번호>.txt`를 (필요하면 여러 번 나눠) 읽는다.
2. 위 스키마로 객체를 만들어 `K-IFRS/parts/<번호>.json`에 **Write**한다.
3. 끝나면 한 줄 요약 반환: `<번호> <명칭>: 문단 N개, 용어 M개`.
